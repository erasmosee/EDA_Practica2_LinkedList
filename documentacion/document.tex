\chapter{Introducción}

En esta práctica hemos implementado una estructura basada en listas enlazadas, concretamente listas doblemente enlazadas circulares.

A partir de la clase común \texttt{DoubleLinkedList} hemos creado una variante sin orden \texttt{UnorderedDoubleLinkedList} y otra con orden \texttt{OrderedDoubleLinkedList}.

El nodo \texttt{Node<T>} guarda referencias a anterior y a siguiente, lo que nos permite recorrer la lista de manera bidireccional conectando el primero con el ultimo.

La lista ordenada tiene la resctriccion de que ha de implementar elementos que implementen \texttt{Comparable<T>}, mientras que la no ordenada tiene mas libertad en cuanto a los elementos que almacena.

Se han realizado pruebas tanto con enteros y objetos \texttt{Persona} para finalmente implementarlo en la practica 1 de Atores y peliculas.

\chapter{Descripción de las estructuras de datos principales}

Sobre las listas doblemente enlazadas, podemos afirmar que si la lista esta vacia, no hay ningun nodo, por lo que \texttt{first == null} y el contador vale cero \texttt{count == 0}. En caso de tener elementos cada nodo desde el primero apuntara tanto al siguiente como al anterior, de manera que el ultimo es accesible desde el primero y el primero desde el ultimo formando un circulo.
En los casos en los que solo hay un nodo, este sea puntara a si mismo. El contador nos permite saber el numero de elementos de manera directa \texttt{O(1)} sin tener que recorrer toda la lista contando elementos, a coste de que cada vez que añadimos o quitamos un elemento de la lista agregar una modificacion al contador.
Cada vez que se añade o se retira un elemento de la lista, hay que actualizar los enlaces del elemento nuevo y de los elementos que rodean al nuevo elemento para que no se rompa la lista.

\begin{lstlisting}[language=Java]
  //Complejidad O(n)
  //busca el nodo cuyo dato es igual a {@code elem}.
  protected Node<T> locate(T elem) {
    if (isEmpty()) {return null;}
    Node<T> aux = first;
    do {
      if (Objects.equals(elem, aux.data)) {return aux;}
      aux = aux.next;
    } while (aux != first);
    return null;
  }
\end{lstlisting}

\section{\label{removeFirst}removeFirst}
\begin{lstlisting}[language=Java]
  //Complejidad O(1)
  //Elimina el primer nodo, actualiza {@code first} y los enlaces entre el nuevo primero y el último.
  public T removeFirst() {
    Node<T> aux;
    if (isEmpty()) {
      throw new NoSuchElementException();
    } else {
      aux = first;
      if (isAlone()) {
        first = null;
      } else {
        first.prev.next = first.next;
        first.next.prev = first.prev;
        first = first.next;
      }
      count--;
    }
    return aux.data;
  }
\end{lstlisting}

\section{\label{removeLast}removeLast}
\begin{lstlisting}[language=Java]
  //Complejidad O(1)
  //Elimina el último nodo y actualiza los enlaces entre el nuevo último y {@code first}.
  public T removeLast() {
    Node<T> aux;
    if (isEmpty()) {
      throw new NoSuchElementException();
    } else {
        aux = first.prev;
        if (isAlone()) {
          first = null;
        } else {
          first.prev.prev.next = first;
          first.prev = first.prev.prev;
        }
        count--;
    }
    return aux.data;
  }
\end{lstlisting}

    if (aux == null) {return null;}
    if (aux == first) {return removeFirst();}

        Node<T> aux;

            return null;

\section{\label{iterator}iterator}

    public Iterator<T> iterator() {return new ListIterator();}
    private class ListIterator implements Iterator<T> {
        private Node<T> aux = first;
        private int contador = count;
        @Override
        public boolean hasNext() {return contador > 0;}
        @Override
        public T next() {
            if (!hasNext()) {throw new NoSuchElementException();}
            T data = aux.data;
            aux = aux.next;
            contador--;
            return data;
        }
    }
\end{lstlisting}

\item Búsqueda de un elemento en lista de un solo elemento:

\begin{itemize}

\item El elemento buscado no está en la lista

\item El elemento buscado está en la mitad de la lista

\end{itemize}
